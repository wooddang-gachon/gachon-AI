# 데이터 전처리(Data Preprocessing)의 개념 및 타이타닉 사례 분석

## 1. 데이터 전처리란?
데이터 전처리(Data Preprocessing)는 확보한 원시 데이터(Raw Data)를 머신러닝 모델이 효과적으로 학습하고 분석할 수 있는 형태로 정제하고 가공하는 필수적인 과정입니다. "쓰레기가 들어가면 쓰레기가 나온다(Garbage In, Garbage Out)"는 데이터 과학의 격언처럼, 모델의 최종 성능은 알고리즘의 우수성보다 입력되는 데이터의 품질에 더 크게 좌우됩니다.

### 1.1 데이터 전처리의 필요성
- **데이터 품질 향상**: 누락된 값(결측치)이나 비정상적인 값(이상치)을 처리하여 데이터의 정확성과 일관성을 확보합니다.
- **학습 효율성 증가**: 불필요한 데이터를 제거하고 차원을 축소하여 모델의 학습 속도를 높이고 연산 비용을 절감합니다.
- **모델 성능 최적화**: 문자를 숫자로 변환(인코딩)하거나 데이터의 범위를 맞추는(스케일링) 작업을 통해 알고리즘이 패턴을 더 쉽게 찾을 수 있도록 돕습니다.

### 1.2 주요 데이터 전처리 과정
1. **데이터 정제 (Data Cleaning)**: 결측치 및 이상치를 식별하고 제거하거나 대체값으로 채웁니다.
2. **데이터 변환 (Data Transformation)**: 범주형 데이터를 수치형으로 변환(Encoding)하거나, 데이터의 단위/분포를 통일(Scaling)합니다.
3. **피처 선택 (Feature Selection)**: 타겟 예측에 가장 큰 영향을 미치는 유의미한 독립 변수들만 선택하여 다중공선성을 방지하고 모델의 과적합을 막습니다.

## 2. 타이타닉 생존자 예측 전처리 사례 (Case Study)
앞서 설명한 데이터 전처리의 개념을 '타이타닉 생존자 예측 모델' 프로젝트에 적용한 실습 사례입니다.

### 2.1 사용 데이터 및 컬럼 설명
분석에 사용된 Kaggle Titanic Dataset(`titanic.csv`)의 주요 컬럼 구성은 다음과 같습니다.
- **PassengerId**: 승객의 고유 번호
- **Survived**: 생존 여부 (0 = 사망, 1 = 생존) **[예측 대상]**
- **Pclass**: 객실 등급 (1 = 1등석, 2 = 2등석, 3 = 3등석)
- **Sex**: 성별 (male, female)
- **Age**: 나이
- **SibSp**: 함께 탑승한 형제자매, 배우자의 수
- **Parch**: 함께 탑승한 부모, 자녀의 수
- **Ticket**: 티켓 번호
- **Fare**: 탑승 요금
- **Cabin**: 객실 번호
- **Embarked**: 탑승 항구 (C = Cherbourg, Q = Queenstown, S = Southampton)

### 2.2 타이타닉 데이터 전처리 실습 과정

#### 1) 결측치 처리 과정의 설계 (Data Cleaning)
데이터셋에 존재하는 빈 값(결측치)을 단순히 삭제하면 귀중한 데이터가 손실(Data Loss)될 위험이 있습니다. 특히 전체 데이터(n수)가 적은 상황에서는 이를 방지하기 위해 빈 공간을 **가장 합리적인 대체값(Imputation)** 으로 채우는 전략을 선택했습니다.

- **나이(`Age`) 결측치 처리**: `Age` 컬럼은 전체 891개 중 약 177개의 결측치가 존재했습니다.
  - **대체값 선정 기준**: 평균(Mean) 대신 **중앙값(Median)** 을 선택했습니다. 평균은 극단적인 나이(예: 아주 고령의 승객)에 의해 값이 크게 왜곡될 수 있는 반면, 중앙값은 이상치(Outlier)의 영향을 최소화하면서 탑승객들의 전반적인 연령 분포를 가장 안정적으로 대변하기 때문입니다. (`df['Age'].fillna(df['Age'].median())`)
- **탑승 항구(`Embarked`) 결측치 처리**: `Embarked` 컬럼은 단 2개의 결측치만 존재했습니다.
  - **대체값 선정 기준**: 범주형 데이터이므로 평균이나 중앙값을 계산할 수 없습니다. 따라서 전체 데이터에서 가장 빈번하게 등장하는 **최빈값(Mode)** 으로 빈 공간을 대체하여 통계적 일관성을 유지했습니다. (`df['Embarked'].fillna(df['Embarked'].mode()[0])`)

#### 2) 데이터 인코딩 (Data Transformation)
머신러닝 알고리즘은 수학적 연산을 기반으로 하므로, 텍스트 형태의 데이터를 이해할 수 없습니다. 이를 해결하기 위해 문자열을 모델이 처리할 수 있는 수치형 데이터로 변환(인코딩)했습니다.
- **성별(`Sex`)**: 가장 직관적인 매핑 방식을 사용하여 남성(male)은 0, 여성(female)은 1로 수치화했습니다. 이는 생존 여부(0, 1)와 동일한 이진 분류 형태를 띠게 됩니다.
- **탑승 항구(`Embarked`)**: 타이타닉 호의 탑승 항구는 크게 3가지('C' = Cherbourg, 'Q' = Queenstown, 'S' = Southampton)의 범주형 문자열로 이루어져 있습니다. 사이킷런(scikit-learn)의 `LabelEncoder` 모듈을 활용하여 이 알파벳들을 알파벳 순서(또는 내부 매핑 기준)에 따라 고유한 정수값으로 자동 변환했습니다. (`df['Embarked'] = le.fit_transform(df['Embarked'].astype(str))`)
  - **변환 결과**: 예를 들어, 'C'는 0, 'Q'는 1, 'S'는 2와 같은 형태의 수치형 범주로 매핑되어, 모델이 각 항구 간의 차이를 인식할 수 있게 됩니다.

#### 3) 피처 선택 (Feature Selection)의 심층 분석
타겟 변수인 `Survived`(생존 여부)를 예측하기 위해, 모든 피처를 모델에 투입하는 대신 **상관관계 분석(Correlation Analysis)** 을 통해 가장 영향력 있는 변수들만 선별했습니다.

- **상관관계(Correlation)와 히트맵(Heatmap)의 활용**:
  - `df.corr(numeric_only=True)`를 사용하여 수치형 변수들 간의 피어슨 상관계수(Pearson Correlation Coefficient)를 계산했습니다. 이는 두 변수가 얼마나 선형적으로 연관되어 있는지를 -1부터 1 사이의 값으로 수치화한 것입니다.
  - 이 수치들을 `seaborn.heatmap`을 통해 색상으로 시각화(히트맵)함으로써, 수많은 변수들 사이의 복잡한 관계를 한눈에 파악했습니다.
- **상관관계 분석 결과 (`Survived` 기준)**:
  히트맵 시각화 결과, `Survived`와 가장 뚜렷한 선형적 연관성을 보이는 주요 변수들은 다음과 같았습니다.
  1. **Pclass (객실 등급)**: 생존율과 강한 음(-)의 상관관계를 보였습니다. 숫자가 작을수록(1등석) 생존율이 높고, 숫자가 클수록(3등석) 생존율이 낮아지는 명확한 추세를 나타냅니다.
  2. **Sex (성별)**: 여성(1)의 생존율이 남성(0)에 비해 월등히 높게 나타나며 가장 강력한 상관성을 보였습니다.
  3. **Fare (요금)**: 생존율과 양(+)의 상관관계를 보였습니다. 요금이 높을수록(1등석과 연관) 생존율이 높았습니다.
- **최종 피처 선정 (`Pclass`, `Sex`, `Age`)**:
  - `Pclass`와 `Sex`는 강한 상관관계를 바탕으로 일차적으로 선택되었습니다.
  - `Fare`는 생존율과 양의 상관관계가 높았지만, 이미 `Pclass`와 매우 강한 연관성(다중공선성)을 갖고 있어 예측의 불안정성을 막기 위해 제외했습니다.
  - 반면, `Age`(나이)는 단독 상관계수는 상대적으로 낮았으나, "어린아이의 생존율이 높다"는 도메인 지식과 결합하여 예측에 필수적인 핵심 변수로 판단하여 최종 리스트에 포함했습니다.

### 2.3 전처리의 효과 및 시사점
- **다중공선성 완화**: 요금(Fare)과 객실 등급(Pclass)처럼 서로 밀접하게 연관된 중복 피처를 피처 선택 과정에서 제거함으로써, 모델이 특정 변수에 과하게 의존하여 학습이 불안정해지는 현상을 성공적으로 방지했습니다.
- **과적합 방지 및 연산 효율성**: 10개가 넘는 모든 피처를 사용하는 대신, 히트맵 분석을 기반으로 검증된 핵심 피처 3개만 선별하여 불필요한 노이즈를 제거했습니다. 이는 새로운 데이터에 대한 일반화 성능을 높이고 연산 비용을 획기적으로 줄이는 결과를 가져왔습니다.
- **결과 해석의 용이성**: 수많은 변수가 섞인 블랙박스 모델보다, 상관계수로 증명된 "성별, 객실 등급, 나이"라는 직관적인 3가지 조건만으로 모델의 판단 근거를 설명할 수 있어 분석 결과에 대한 설득력이 매우 높아졌습니다.

**결론적으로**, 전처리 과정을 거친 후 단 3개의 핵심 피처만으로도 약 80.2%(Random Forest 기준)라는 방어력 높은 정확도를 기록했습니다. 이는 단순하게 많은 데이터를 모델에 입력하는 것보다, 결측치를 합리적으로 대체하여 데이터 손실을 막고, 문자를 수치로 인코딩하여 모델의 접근성을 높이며, 상관관계 분석을 통해 핵심 신호(Signal)만 추출하는 전처리 과정이 머신러닝 모델의 성능과 신뢰성에 결정적인 영향을 미친다는 것을 입증합니다.
